# radar-plotting-sheet

ブラウザで使えるレーダー・プロッティング用紙です。自船の針路・速力と、他船の観測値（時刻・真方位・距離）を入れると、作図を手順ごとに描きます。数値だけでなく「どんな形の図になるか」を目で確かめるための学習用サイトです。

ビルド不要の静的サイトで、Cloudflare Pages にそのまま載せられます。

## できること

- 外周に方位目盛り、同心円に距離を持つプロッティング用紙を表示する（レンジは 3〜48 海里、自動選択あり）
- 作図を 6 つの手順に分けて、1 つずつ進めながら表示する
  1. プロット（M1、M2…）
  2. 相対運動線（相対針路・相対速力）
  3. CPA（DCPA・TCPA）
  4. 速力三角形（他船の真針路・真速力）
  5. アスペクト（R／G。方位に ±180° する理由を図で示す）
  6. 避航（CPA を指定の距離にする変針・変速、船首方向の指定距離を通過させる変速）
- 結果の表も手順に合わせて開くので、先に自分で作図してから答え合わせができる
- 速力三角形だけを拡大した図を並べて表示する
- 物標は 3 隻まで、観測は 1 隻につき 4 回まで
- 速力三角形の描き方を 2 通りから選べる（選んだ方式はその端末に覚える）
  - 距離ベクトル方式：最初の観測点の所に、観測の間に進む距離で小さく描く
  - 速力ベクトル方式：中心から自船と他船の矢印を速力の長さで大きく描き、相対運動線を平行に移して（転移して）先端どうしをつなぐ。避航の作図もこの大きい三角形の上で行う
- 印刷モード：A4 横 1 枚に、用紙（左）と「自船と観測」「結果」「速力三角形の拡大図」の 3 つの枠（右）を並べたレポートを印刷する
  - 数値だけを載せた問題用紙（作図と答えは空欄）と、白紙の用紙も印刷できる
  - 用紙の下に、同じ縮尺の距離目盛りが付く（ディバイダで距離を取る用）
- 入力した値をリンクに入れて共有する

## 使い方

1. 「自船」に真針路と速力を入れる。
2. 「物標」に観測を古い順に入れる。時刻は `1006` のような 4 桁、真方位は度、距離は海里。
3. 用紙の下の手順ボタン、または「前へ」「次へ」で作図を進める。
4. 避航の作図をするときは「避航の作図をする」にチェックを入れ、動作を始める時刻と距離を入れる。
5. 紙に出すときは右上の「印刷モード」を開き、内容（レポート／問題用紙／問題用紙＋レポート／白紙の用紙）を選んで「印刷する」を押す。用紙は A4 の横向き。

用紙はピンチか Ctrl（⌘）＋ホイールで拡大でき、拡大中はドラッグで動かせます。「三角形を拡大」で速力三角形の所へ寄ります。

## 計算の前提

- 座標は北を上、方位は真方位（北から時計回り）。距離は海里、速力はノット。
- 相対運動線は、最初と最後の観測点を結ぶ直線とする。
- 距離ベクトル方式の速力三角形は、最初の観測点から自船の針路と反対向きに、観測の間に自船が進む距離を取った点を e とする。e→最初の点が自船、e→最後の点が他船の真の動き。
- 速力ベクトル方式では、中心から自船の矢印（真針路・速力）を引き、その先端から相対針路の向きに相対速力の長さを取る。中心からその先へ引いた矢印が他船の真の動き。矢印の縮尺は「1 海里の目盛り＝1・2・4・5・10 ノット」のうち、いちばん速い船が用紙に収まる最小のものを自動で選ぶ。
- アスペクトは「他船の真針路 −（他船の真方位 ± 180°）」。＋は左舷（R）、−は右舷（G）。
- 避航は、他船が針路・速力を変えないものとして、新しい相対運動線と平行になる自船の針路または速力を求める。変針は速力一定で 2 通りまで、変速は針路一定で 1 通り。
  - 速力ベクトル方式では、新しい相対運動線を他船の矢印の先端へ平行に移して逆向きに延ばす。新しい自船の矢印の先端はこの線の上に来るので、針路だけ変えるなら自船の速力を半径とする円との交点、速力だけ変えるなら元の針路線との交点になる。
  - 平行に移した線どうしには、同じ数の矢羽根の印（＞）を付けて対応が分かるようにしている。

手で作図して読み取る値は線の引き方で少し変わるので、このサイトの値と完全には一致しません。

## 開発

依存パッケージはありません。Node.js はテストにだけ使います。

```bash
npm run dev    # http://localhost:8787 で public/ を配信（Python 3 の http.server）
npm test       # 計算部分のテスト（node --test）
```

```
public/
  index.html
  styles.css
  _headers          Cloudflare Pages が付けるレスポンスヘッダー（CSP など）
  js/
    geometry.js     ベクトル・方位・交点などの幾何
    solve.js        相対運動、CPA、速力三角形、アスペクト、避航の計算
    model.js        入力された文字列から計算結果をまとめる
    render.js       用紙と作図の SVG 描画
    print.js        印刷モードのページ（A4 横）
    app.js          入力フォーム、手順、結果の表、拡大と移動、印刷モード
    presets.js      例題
    format.js       数値の表記
test/
  solve.test.js     計算
  render.test.js    作図（2 つの方式、手順ごとの表示）
  print.test.js     印刷ページ（問題用紙に答えが出ないこと、など）
wrangler.toml       Cloudflare Pages の設定（出力ディレクトリは public）
```

## Cloudflare Pages で公開する

### Git 連携（push するたびに自動で公開）

1. Cloudflare ダッシュボードの Workers & Pages で Pages のプロジェクトを作り、このリポジトリを接続する。
2. ビルドの設定は次のとおり。
   - Framework preset: `None`
   - Build command: 空欄（入力が必須と言われたら `exit 0`）
   - Build output directory: `public`
3. 保存してデプロイする。以後は `main` への push で本番が更新される。

`wrangler.toml` に `pages_build_output_dir = "public"` を書いてあるので、出力ディレクトリはこのファイルが優先されます。

### Wrangler から直接アップロードする場合

```bash
npx wrangler pages project create radar-plotting-sheet --production-branch main
npx wrangler pages deploy public --project-name radar-plotting-sheet
```

直接アップロードで作ったプロジェクトは、あとから Git 連携に切り替えられません。自動で公開したい場合は、最初から Git 連携で作ってください。

## 注意

学習用の作図補助です。実際の航海や衝突回避の判断には使わないでください。
